Detailed Description

template<typename T>
class TinyVector< T >

Dynamic array of T with copy semantics. T needs a default constructor and a copy constructor.

TinyVector<int> v;
v.push_back(1);
for (size_t i = 0; i < v.size(); i++) { ... v[i] ... }

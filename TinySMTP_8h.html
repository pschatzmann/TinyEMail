Detailed Description

Header-only SMTP client for Gmail with an Arduino style API.

The connection is a Stream (read) and a Print (write). On top of it, the SMTP commands: EHLO, AUTH PLAIN, MAIL FROM, RCPT TO, DATA and QUIT. The message of DATA can be plain text or MIME with base64 attachments.

Detailed Description

IMAP client for Gmail: transport plus IMAP commands.

Usage (reading the mail of the inbox):

WiFiClientSecure secure;
TinyIMAP imap(secure);
if (imap.begin() && imap.readGreeting() &&
imap.login("me@gmail.com", "abcdefghijklmnop") && // App Password
imap.select("INBOX")) {
String uids; // "4 7 12", the UIDs of the unread mails
if (imap.searchList("UNSEEN", uids)) {
// parse the numbers of uids, and for each uid:
String message;
if (imap.fetchMessage(4, message)) {
// message holds the complete RFC 822 text
}
}
imap.logout();
}
imap.end();
TinyIMAP
IMAP client for Gmail: transport plus IMAP commands.
Definition TinyIMAP.h:50

Every command returns true if the server answered with a tagged OK. The server's last tagged response is available with lastResponse(). Message data is returned as a String, so binary data with NUL bytes is not supported.

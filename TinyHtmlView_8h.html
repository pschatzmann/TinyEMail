Detailed Description

Simple streaming HTML renderer drawn with TinyFonts (TinyMaterialDesign widget).

The content is never loaded into memory: the renderer reads the mail file through the File API one byte at a time, lays out words and draws each word at its position. Scrolling is done by the Container that holds the view.

Supported: paragraphs, headings (h1-h6), line breaks, list items, entities (& < > " &#NN; ...). Script, style, head and comments are skipped. Links, images, tables and fonts are shown as their text only. The text is UTF-8; charsets other than UTF-8 are not converted.

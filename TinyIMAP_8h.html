Detailed Description

Header-only IMAP client for Gmail with an Arduino style API.

Reads mail from Gmail (imap.gmail.com:993, implicit TLS). Implemented commands: LOGIN, SELECT, UID SEARCH, UID FETCH (BODY.PEEK, so the messages are not marked as read) and LOGOUT.

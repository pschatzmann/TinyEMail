Detailed Description

E-mail client with a GUI for TinyMaterialDesign (portrait screens, 240x320 and larger).

Screens:

  • list of the stored mails (subject and sender); the menu (top right) has Fetch, Setup and Exit
  • one mail: the app bar has a back arrow and the subject; below it the sender, a row per attachment, a divider and the body (HTML rendered with TinyFonts)
  • one attachment: a text file is shown as text; any other file shows its name and size (it stays in the mail folder on the storage)
  • login: shown when Fetch cannot log in or cannot reach the network

Every mail is stored on the SD card (see TinyMailStore), each attachment as a file of its own. Needs TinyMaterialDesign (with TinyGPU) and TinyFonts, so include this header only in sketches that use them:

App<RGB565> app(board); TinyEMailGUI gui(app, {"me@gmail.com", "app-password", 10, "mails.img"});

void setup() { app.begin(); gui.begin(); } void loop() { gui.tick(); app.update(); }

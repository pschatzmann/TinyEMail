Detailed Description

Sends and receives mail with a simple API.

WiFiClientSecure secure;
TinyEMail mail(secure);
mail.login("me@gmail.com", "abcdefghijklmnop"); // Gmail App Password
mail.send("you@example.com", "Hello", "Sent from an ESP32.");
mail.receive([](const TinyEMail::Mail& m) {
for (TinyPart& part : m.parts()) {
if (part.info.contentType == "text/plain") Serial.println(part.data.readString());
}
return true; // false stops
});

◆ receive()

template<typename Callback >
int TinyEMail::receive ( Callback  callback,
Filter  filter = Filter::Unread 
)
inline

Calls callback(mail) for each mail in the INBOX.

The mail has the uid, from, subject and headers. Its parts (the text body, HTML alternatives and attachments) are read with a range based for loop: for (TinyPart& part : mail.parts()). Return true to get the next mail, false to stop. The mails are read without marking them as read.

The IMAP connection is open while the callback runs, so do not call send() or login() from it.

mail.receive([](const TinyEMail::Mail& m) {
for (TinyPart& part : m.parts()) {
if (part.info.contentType == "text/plain") Serial.println(part.data.readString());
}
return true;
}, TinyEMail::Filter::Unread);

◆ send() [3/3]

bool TinyEMail::send ( const Mail &  mail)
inline

Sends a mail from the logged in account.

Uses mail.to, mail.subject and mail.attachments. The first attachment is the text body (a text type, e.g. text/plain or text/html). Each further attachment is a file, base64 encoded while it is sent. A mail with only the text is plain text; with files it is MIME multipart.

Returns
true if the server accepted the mail

Detailed Description

A small vector for Arduino. Its memory comes from PSRAM when the board has it, otherwise from the normal heap.

On the ESP32 Arduino core, BOARD_HAS_PSRAM is defined for boards with PSRAM enabled. Define TINY_EMAIL_USE_PSRAM to use PSRAM in any case. If PSRAM cannot give the memory at run time, the normal heap is used.

Detailed Description

The data of one part of a mail, decoded while it is read (base64 and quoted-printable). A Stream: read() gives the next byte, -1 at the end.

Use writeTo() to copy the data to a File or another Print, or readString() for text. Do not use readBytes(): at the end of the data it waits for the timeout. The data can be read once, and only while its part is current.

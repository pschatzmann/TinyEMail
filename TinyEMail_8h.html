Detailed Description

Header-only e-mail client for Gmail with an Arduino style API.

TinyEMail sends and receives mail with three methods: login(), send() and receive(). It uses TinySMTP to send and TinyIMAP to read; both work on the same Arduino Client (for example WiFiClientSecure), one connection at a time.

The defaults are the Gmail servers. setSmtpServer() and setImapServer() select other servers. Errors and warnings are written to the TinyLogger.

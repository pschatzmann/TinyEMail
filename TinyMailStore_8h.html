Detailed Description

Stores mails in a FAT file system, using TinyFATFS.

The storage is given as a TinyFATFS driver: fatfs::ArduinoSpiIO for an SD card on an Arduino board, fatfs::FileIO (a disk image file) on the desktop.

Layout (the stored mails are the folders m<uid> of mails/, found by a scan): mails/m<uid>/mail.txt From, Subject and one Attachment line per file mails/m<uid>/body.html the HTML body of the mail (if it has one) mails/m<uid>/body.txt the text body of the mail (if it has one) mails/m<uid>/<name> each attachment as a file

The parts are copied to their files while they are read, and the bodies are rendered from their files as well: no mail is ever held in RAM as a whole.

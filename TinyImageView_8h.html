Detailed Description

Shows a picture attachment: JPEG, PNG, GIF or BMP.

JPEG is decoded with TinyJPEG (TinyGPU's JPEGParser) while the file is read, so the file is never held in memory. PNG, GIF and BMP are decoded from memory; they are limited to kMaxBufferedBytes. The decoded picture is kept in a FrameBuffer of its own size.

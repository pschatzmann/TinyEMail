Detailed Description

The parts of a received mail. Use it in a range based for loop:

for (TinyPart& part : mail.parts()) {
if (part.info.attachment) {
part.data.writeTo(file); // or part.data.readString()
}
}
TinyPart
One part of a received mail, as given by a for loop over mail.parts()
Definition TinyMIMEReader.h:702

The parts are read from the message as the loop goes: each part is read in order, once. Only the part that is current is kept in RAM.

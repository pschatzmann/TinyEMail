Detailed Description

SMTP connection with the commands for sending mail.

Usage (sending a mail step by step):

WiFiClientSecure secure;
TinySMTP smtp(secure);
if (smtp.begin() && smtp.readReply() == 220 && // smtp.gmail.com:465
smtp.ehlo("esp32") &&
smtp.authPlain("me@gmail.com", "abcdefghijklmnop") && // App Password
smtp.mailFrom("me@gmail.com") &&
smtp.rcptTo("you@example.com") &&
smtp.data("Subject: Hello\r\n\r\nSent from an ESP32.\r\n")) {
smtp.quit();
}
smtp.end();
TinySMTP
SMTP connection with the commands for sending mail.
Definition TinySMTP.h:43

Every command returns true if the server answered with the expected reply code. The last reply is available with lastReplyCode() and lastReply(). For most uses TinyEMail is simpler.
